# fOS v3.0.0-beta.1 Release Notes

Release date: 2026-07-28

## Highlights
fOS 3.0.0-beta.1 adds customizable themes, custom folders, Text app subfolder support, an updated UI Demo and a Monday-first calendar.

## Added
* Blue, Orange and Green themes.
* Theme support in native and SD apps.
* `bg=theme`, `bg=surface`, `fg=contrast`.
* Custom folder creation.
* Save/load text files in subfolders (`folder/file.txt`).

## Changed
* Updated ui_demo and button_demo.
* Calendar now starts with Monday instead of Sunday.
