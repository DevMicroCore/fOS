# fOS v3.1.0 Release Notes

## Highlights

fOS 3.1.0 updates the Weather application with a new location search feature.

## Weather Application

* Added a **Search** button.
* The Search button opens a location search menu.
* A location can be entered manually.
* Pressing the **✅** button starts the search.
* All matching results are displayed in a dropdown menu.
* The desired location can then be selected from the dropdown menu.

## Compatibility

* Existing Weather application functionality remains available.
* Existing SD application support remains unchanged.
